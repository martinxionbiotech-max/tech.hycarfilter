# 空调滤关键参数

!!! note "来源性质"
    本文为编辑原创整合。**[行业常识]** = 行业通用做法；**[框架参考]** = 标准框架介绍；**[编辑观点]** = 研究员原创判断。型号规格以 [data.hycarfilter](https://data.hycarfilter.com) 为准。回链：[data 空调滤品类](https://data.hycarfilter.com/products/cabin-filter/)。

空调滤（座舱滤清器）保护的是**人**而不是机器——它过滤车外进入座舱的空气。评价标准因此从「保护发动机」转向「保护乘员健康与舒适」，参数逻辑与其他品类不同。

## 一、参数清单

| 参数 | 定义 | 本站同值（data） |
|---|---|---|
| 颗粒过滤效率 | 对颗粒物（花粉/粉尘/PM）的拦截率 | `hy-cf-particle` >=95% · `hy-cf-carbon` >=96% · `hy-cf-hepa` >=99.97% (H13) |
| 气体吸附 | 活性炭对 VOC/异味/尾气吸附 | `hy-cf-carbon`/`hy-cf-hepa` 含活性炭层 |
| 风量 / 压差 | 座舱送风阻力 | 数据以 data 站为准（低压差优先） |
| 外形 | 长×宽×高 | `hy-cf-*` 均为 240×200×30 mm |

## 二、三个档位的定位

**[行业常识]**

- **颗粒型**（`hy-cf-particle` >=95%）：基础款，拦花粉/大颗粒粉尘；
- **活性炭型**（`hy-cf-carbon` >=96%）：颗粒 + 活性炭，兼顾异味/VOC 吸附，城市通勤主流；
- **HEPA 型**（`hy-cf-hepa` >=99.97% H13）：接近医疗级颗粒拦截，配合活性炭，面向高端车型/过敏人群/空气污染严重地区。

**[编辑观点]** H13 的 `99.97%` 指的是**对 0.3 µm（最易穿透粒径 MPPS）颗粒**的拦截率——这是 HEPA 标准的定义口径，与空滤的「ISO 5011 试验粉尘效率」口径不同，**不可跨品类直接比较数字大小**。别把空调滤的 99.97% 和空滤的 99.5% 拿来比「谁更高级」，它们测的不是同一种颗粒。

## 三、测量方法

**[框架参考]**

1. **颗粒效率**：参考 HEPA/EN 1822 或 ISO 16890 框架，测对特定粒径段（如 0.3–2.5 µm）的拦截率；
2. **气体吸附**：活性炭层对特定气体（甲苯/甲醛等）的吸附效率与容量试验；
3. **风量/压差**：标称风量下测压差，评估对空调送风的影响。

## 四、参数对使用体验的影响

**[行业常识]**

- **效率过高 → 风量下降**：HEPA 滤材阻力大，若整车空调风机匹配不当，会导致制冷/制热风量变小；故 HEPA 款需与车型风机能力匹配；
- **活性炭容量**：活性炭会「吸附饱和」，饱和后吸附失效但颗粒过滤仍在；因此活性炭款需按里程定期更换，周期短于纯颗粒款；
- **尺寸贴合**：座舱滤芯格是硬尺寸，尺寸偏差会导致漏风短路（未过滤空气从缝隙直入）。
